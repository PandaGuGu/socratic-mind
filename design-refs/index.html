四个方向，以及它们各自偷自哪里

指向的都是 GitHub 上真实可读源码的项目。每条方向我给了一个用你现有文案渲染的预览——不是效果图，是能点、能改的 HTML。

房间，现在的问题

  1. 暗得没有层次。墙、地面、小人都在 #1a1a1a 附近，没有明确光源，结果是"发灰"而不是"入夜"。
  2. 文字在跟场景抢注意力。浅灰字压在渐变上，两行字权重相同，没有主句。
  3. 五颗石子是好主意，但形态太弱。既不像进度也不像动作，看不出"我在第几步"。
  4. 开发信息进了画面。左下角"已就绪"这类字样不该出现在用户的房间里。

控制台，现在的问题

  1. 层级靠边框而不是留白。三栏全用 1px 线切，眼睛要靠线找结构。
  2. 元信息淹没正文。会话 id 满屏且字号与正文同级，该用等宽小字压到 45% 不透明度。
  3. 没有颜色预算。绿黄红紫同时出现，安全暂停这类关键状态反而失去重量。
  4. 密度不匹配。左列很松、右列很密，中间流程卡最好看，却没被当成视觉主体。
方向 A

深夜静室

保留你现在的房间，只把"暗"做对：一个光源、一层地面、一个可点的东西。改动最小，风险最低。

A / 唯一光源 = 唯一焦点 · 悬停时光池变亮
doublespeakgames / adarkroom8.4k

A Dark Room：全屏黑底、一行字、一个按钮。十年了还是"少即是多"最好的样本。

可偷：文本一次只出一行，永不滚动；按钮就是全部交互，没有图标。
remvze / moodist4.0k

环境音工具，深色、极静、控件几乎隐形。同类情绪产品里完成度最高的一档。

可偷：控件 hover 才出现；分隔线用 6% 白而不是灰；圆角极小。
meditohq / medito-app1.3k

免费冥想 App（Flutter），整套配色与字号规范都写在仓库里，可直接抄色板。

可偷：低饱和暖灰做背景，正文不用纯白；标题与正文只差 1.4 倍大小。
光

墙压到 #0b0908，唯一光源是窗与地面光池（radial-gradient + blur）。除光池外的一切退到 4% 亮度，暗才成立。

字

砍掉"标题 + 副标题"结构：只留一句 17px 衬线，第二行 13px、60% 亮度、延迟 400ms 淡入。

动作

房间里只有一个小人可点。其余元素默认 opacity 0，hover 到 0.35，不做任何弹跳动画。

自托管日记 + 情绪记录，浅色纸感界面，日期与条目排得像一本真的本子。

Nicky Case 的系统思考工具。手绘感但不幼稚——证明"温和"不等于"卡通"。

可偷：整体只用一个墨色 + 一个强调色；线条粗细固定 2px，不做渐变。
journiv / journiv-app1.3k

另一套自托管日记，结构更接近"一问一答"，可以直接对照你的五阶段。

可偷：左侧极窄的日期轴 + 右侧单列正文，永不加第三个面板。
底

#F6F2EA 纸色，正文 #2A2724 墨色，绝不用纯黑纯白。噪点用 4px 点阵，透明度 0.5。

字

手写/衬线只用于"当前问题"，其余标签、按钮全部无衬线，避免整页变成文艺海报。

进度

五颗石子改成五个实心点 + STEP 1/5 等宽小字，进度不再是谜语。

C / 一屏一问 · 进度是一条线，不是五颗石子
shadcn-ui / ui129k

不是视觉风格，是"克制"的工程范本：默认无阴影、无渐变、边框即结构。

可偷：focus 环与键盘导航的默认值；所有交互态都在 150ms 内完成。
ibelick / motion-primitives7.0k

一组动画原语，专门解决"页面切换不突兀"这种小事，代码短到能读完。

可偷：文字切换用 opacity + 6px 位移 + 400ms，别用打字机效果。
tremorlabs / tremor3.7k

图表与指标的默认样式库——后台那 191ms、201ms 的耗时条可以直接用它。

可偷：数字一律 tabular-nums；指标卡只用一个主色 + 灰阶。
尺度

字号 clamp(28px, 4.2vw, 44px)，行高 1.5，每行最多 22 字。留白至少占屏 60%。

进度

1px 线 + 当前点（5px 圆），比五颗石子信息量更高、视觉噪音更低。

次要操作

重开、导出、设置全部收进左下角一个"…"，11px、字距 0.08em，不参与视觉竞争。

方向 D

微光空间

房间还是房间，但换成真的三维：真实光照、极慢的呼吸式运镜，UI 贴在世界里而不是浮在画面上。最贵，也最容易做砸。

D / 相机固定，只做 0.6° 微动 · 光用真实衰减
pmndrs / uikit3.3k

把 React 组件渲染进 three.js 世界。想让"弹出的纸片"有真实厚度，就看它。

可偷：面板贴在世界坐标里随相机走，而不是 fixed 在屏幕角落。
pmndrs / react-three-fiber33.9k

声明式 three.js，生态里阴影、后期、后处理都是现成的。

可偷：只用一盏点光 + 一盏环境光；接触阴影比任何 glow 都更"稳"。
brunosimon / folio-20194.7k

个人站，但三维场景的组织方式是教科书级的：分组、LOD、按需渲染。

可偷：空闲时降到 30fps，交互时才升 60fps，笔记本风扇不会叫。
动

相机不动，只做 0.6°、7 秒周期的微摆。比任何 hover 特效都更让人觉得"这屋子是活的"。

光

用 PBR 真实衰减，别用 CSS 手绘阴影——手绘阴影一多，画面立刻变廉价。

代价

工作量约为 A 的 3–5 倍，且要处理低端机降级。只在房间是核心卖点时才值得。

另一半

控制台往哪走

后台不需要氛围，需要可扫读。这四个项目的共同点：留白分层、颜色有预算、数字用等宽。

仓库能借的star
langfuse / langfuse 最接近你的"轨迹"面板：左侧一条竖线串起轮次，耗时右对齐等宽，标签用描边不用填充。 37.9k
twentyhq / twenty 三栏布局的现代解法：左侧窄导航、中间列表、右侧详情，层级全靠留白与字号，不靠边框。 61.5k
makeplane / plane 高密度列表仍可扫读的做法：行高 36px、状态用 6px 圆点 + 文字，不用彩色胶囊。 63.2k
openstatusHQ / openstatus 小团队后台的克制样本：单一主色、几乎没有阴影、图表与文字同色系。 9.3k
颜色预算

一个主色 + 一个警示色，其余全是灰阶。安全暂停用"红点 + 文字"，不要红底整条。

ID 的处理

一律 mono 11px、透明度 45%，只在标题处显示完整 ID，列表里截断到 8 位。

结构

去掉 80% 的竖分隔线，改用 24px 留白 + 一级标题字号差，眼睛会自己分组。

我的判断

房间走 A：你已经有房间、有小人和五颗石子，缺的不是概念而是光与层级，一天能改完，且能立刻截图对比。控制台先做两件事——照 Langfuse 重排轨迹、砍到两个颜色，比换框架收益大得多。

B 值得做一个分支试色：CBT 用户白天打开的次数远多于夜里，浅色版本可能才是主力；C 是长期的干净答案，但要求文案能一句话立住；D 等房间被验证是卖点之后再投入。

想先看 A 的可交互稿？ 还是先试 B 的浅色分支？ 或者先重排控制台？
