# 认知行为疗法的认知模型

认知行为疗法（CBT）把"想法—情绪—行为"看成一个相互影响的循环。同一件事，不同的解释会带来不同的情绪与行动，而行动的结果又会反过来强化原来的解释。

## 三个层次

认知模型通常分三层：最表层是自动思维，中间是中间信念（规则、假设、态度），最底层是核心信念。

自动思维是情境触发后第一时间冒出来的那句话，例如"我肯定会搞砸"。它出现得很快，往往来不及察觉，伴随明显的情绪和身体反应。

中间信念常以"如果……就……"或"应该……"的形式出现，例如"如果我表现不好，就说明我不行"。

核心信念是对自我、他人、世界的基本判断，例如"我不够好""别人会离开我"。它跨情境稳定，通常需要更长时间的工作才能触及。

## 自动思维的特征

自动思维有三个可观察的特征：与具体情境绑定、出现速度快、内容常带有预测或评价。

因为它是预测而不是事实，所以可以被检验。这一点是认知检验能够成立的前提。

## 认知检验的一般步骤

第一步，记录具体情境：什么时候、在哪里、和谁、发生了什么。

第二步，写下当时的自动思维，并给情绪打分（0 到 10）。

第三步，分别列出支持这条想法的证据和反对它的证据。证据指的是可被他人核对的事实，不包括感受和推测。

第四步，在此基础上形成一个更平衡的说法。它不必是积极的，只需要更接近事实。

第五步，重新给情绪打分，比较前后变化。

## 行为实验

当一条预测可以被具体检验时，可以设计行为实验：把预测写成可观察的形式，执行一次，记录实际结果。

行为实验与"说服自己"不同，前者依赖新信息，后者依赖反复安慰。

## 常见误解

CBT 不是"积极思考"，也不是把负面想法替换成正面口号。它的目标是让结论更贴近证据，而不是更好听。

CBT 也不要求一次就想通。多数改变来自反复的小幅修正，而不是某一次顿悟。
