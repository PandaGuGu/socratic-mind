# 敏感词库：scope|category|action|word
#
# scope  : in（只看用户输入）/ out（只看模型输出）/ both
# action : block（整句拦下，不推进流程）/ mask（打码，输出侧命中要重写）/ review（放行但进复核）
#
# 三条设计约定：
# 1. 自伤/伤人**不在这里**。那类表达要按语境分流（本人/他人/引用），由 SafetyScreener
#    的规则表处理；词库只做"脏东西"和"拉客"，两者混在一起会把"我想死"降级成一个违禁词。
# 2. 词库宁窄勿宽。"废物""没用""安眠药"这类词是 CBT 的原料，用户会反复说，
#    把它们当敏感词会把治疗性对话直接掐死。
# 3. 中文词按"去掉标点与空白后的连续串"匹配，所以不用写"加 微 信"这类变体；
#    全角、零宽、重复字在归一化阶段已经处理。
