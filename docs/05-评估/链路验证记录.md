## 2. 自动化测试

```
mvn -B test
Tests run: 3  ChunkingTest            （切分边界、父块引用、标题链）
Tests run: 4  CitationVerifierTest    （编号有效性、未支撑陈述、免责声明不计入）
Tests run: 4  KnowledgeChainTest      （全链路、拒答、草稿不可检索、发布后可检索）
BUILD SUCCESS
```

三条最关键的断言：

1. `recommendationAndConditionMustStayTogether` —— 推荐意见与其否定条件必须留在同一块；
2. `citationNumberOutsidePackIsRejected` —— 回答引用 `[5]` 但只有 2 条证据时，校验必须失败；
3. `draftDocumentsAreNotRetrievable` —— 未发布文档绝不进入检索候选集。

## 3. 端到端（HTTP）

命令：`bash scripts/e2e.sh`（服务已启动）。

### 3.1 知识库现状

```json
{"documents": 4, "published": 4, "chunks": 18}
```

示例语料 3 份（认知模型 / 焦虑表现 / 能力边界），17 个子块；第 4 份是本次脚本上传的草稿。

### 3.2 正常问答

```json
{
  "status": "answered",
  "answer": "根据资料：认知模型通常分三层：最表层是自动思维，中间是中间信念（规则、假设、态度），最底层是核心信念。[1]",
  "citations": [{"number": 1, "documentTitle": "认知行为疗法的认知模型", "section": "三个层次"}],
  "verification": {"allCitationsValid": true, "citationCoverage": 1.0, "invalidCitationNums": [], "unsupportedClaims": []}
}
```

节点轨迹（`trace`）逐条可查：

```
classify_query → cbt_technique
rewrite_query → 自动思维和核心信念有什么区别？ 负性自动思维 认知模型 中间信念 核心信念 认知…
retrieve_evidence → 4 hits
evaluate_evidence → sufficient=true (命中 4 条，相关性 0.39，双路一致=true)
generate_answer → 51 chars, by stub-evidence-grounded
verify_citations → valid=true coverage=1.0
format_response
```

### 3.3 无资料的问题（必须拒答）

```json
{
  "status": "insufficient_evidence",
  "answer": "现有资料不足以回答这一点。\n\n原因：相关性不足（最高 0.06，命中 4 条），按保守策略降级。…"
}
```

注意：**检索仍然命中了 4 条**。如果只看命中数量，这个问题会被"答"出来。判定依据是相关性阈值 + 双路一致，不是"有没有返回结果"——这是本次验证改掉的一个真实缺陷。

### 3.4 草稿闸门

```
上传草稿 → documentId=doc_v4w（status=draft）
提问「固定起床时间对生物钟有什么作用」→ status = insufficient_evidence
审核 approve → status = published
再提问 → status = answered
answer = 根据资料：固定的起床时间比固定的入睡时间更容易维持生物钟的稳定。[1]
verify = {allCitationsValid: true, citationCoverage: 1.0}
```

这条链路证明"上传 ≠ 可检索"不是文档里的一句话，而是代码里的一个过滤条件。

## 4. 本次验证中修掉的缺陷

| 缺陷 | 现象 | 修法 |
|-|-|-|
| 数据源自动配置 | 内存档启动即失败（找不到 DataSource） | 排除 `DataSourceAutoConfiguration`，改为只在 `postgres` 档装配数据源 |
| 证据充分性只看数量 | 无关问题因"命中 4 条"被判为有依据 | 引入相关性阈值（词法重合 ≥ 0.12）+ 双路一致，见 `EvidenceAssembler` |
| 切句吞掉引用 | `结论。[1]` 被切成两句，引用覆盖率算成 0 | 换成正则分词，句末引用并入本句 |
| 引用重复标题 | 引用显示为「书名 · 书名 > 章节」 | 解析时跳过根级标题 |
| 桩输出混入免责声明 | 免责声明被算作"无引用的事实陈述"，污染指标 | 正文只留答案，来源信息放 `generatedBy` |
