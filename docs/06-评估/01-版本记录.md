## v0.6.1 转介与联系人

2026-11-27。一次不改变流程、但改变"这段话对谁说"的修订。

- **转介不写死号码**：危机卡片与安全暂停话术改为"你所在地区的急救电话 / 心理援助热线"。
  号码写死最坏的结果不是不精确，而是让另一个地区的用户在真正的危机里拨错地方；
  需要本地号码时由部署方按服务地区传入（`CrisisCard.of(session, reason, contacts)`）。
  理由见 [安全与转介 §4](../03-设计/02-安全与转介.md)、[ADR-0004](../04-adr/ADR-0004-产品边界停在不诊断.md) 的修订备注。
- **账号级紧急联系人**：登录后可在账号页填一次，新开的一轮自动带上；
  会话里填过的人优先，两边互不写回。注销账号时一并删除。
- **MIT 协议**：仓库补上 `LICENSE`，文档与 README 同步。
- 测试 202 → 206（转介文案、联系人读写与预填）。

## v0.6.0 运营收口

把"后台能改"推进到"后台能管"：不改代码就能换流程、换模型、查审核、导出记录。

- **画布成为库**：新建、复制、改名、删除，各有草稿与已发布两份；存草稿不动线上，
  单独"启用"才切换运行时；支持右键设起点，起点必须能走到总结。
- **审核扩面**：对象从规则扩到安全规则、词库、流程、输出策略、限流、会话六类；
  每条留版本、署名（取自登录身份）、时间与清单；改版自动回到待审。
- **模型三档热切换**：云端 API / 本地 Ollama / 桩，保存即生效；带连通性测试与本地模型状态。
- **记录能带走**：账号页可导出账号信息与自己的对话（JSON/Markdown），只导出本人会话，不带内部轨迹。
- **会话复核**：逐轮看用户表达，标记风险并上报；仍是辅助提示，不替代临床判断。

证明：202 项测试；H2 与容器档实跑多画布、起点迁移、六类审核署名、模型切换、导出预览。

边界：多画布只在单实例验证，跨实例并发编辑没有锁；导出是同步生成，数据量大时占用请求线程；
云端模型成本与延迟未做长期压测。

## v0.5.1 检索与治理

没有新页面、没有新话术，做的是"让已经有的东西能被证明"。

- **重排四档**（`none` / `lexical` / `fixture` / `http`），`pool-factor=3`：
  召回先放大、重排后再截断。顺序反了等于没排。
- **语料生命周期**：按 `external_key` 去重、按 `content_hash` 决定是否重做；改版回到待审；
  软删除立即退出检索。
- **ACL 在检索前过滤**：修掉"`null` 表示不过滤"的漏洞——设了 ACL 之后，前台匿名调用只能看公开资料。
- **组织域与真登录**：租户/团队/成员落库；系统令牌证明来源，操作者令牌证明身份；
  口令登录 + HttpOnly 会话 + CSRF 双提交；署名只认会话。
- **多实例**：审核记录、评测留痕、限流计数可落库；H2 与 PG 共用 DDL。

证明：194 项测试；真实实例冒烟——无操作者 401、伪造团队 400、无 CSRF 403、带 CSRF 签字 200 且署名正确。

边界：容器档与 PG 档本版未重跑；重排未接真模型；离线评估集未扩容。

## v0.5.0 完整版

把此前分四批记录的迭代合并为一次发布（代码注释里的 v0.4.0–v0.7.0 是合并前的内部标记）。

**需求对齐**：语音输入（浏览器内转写，不录音不落库）、情绪刻度（自报 0–10，≤3 只标"关注"）、
危机卡片（热线 + 自留联系人 + 可复制的话，不代发）、紧急联系人、9 类认知偏差候选、
敏感词三级动作、心理专用 System Prompt、会话表新增可空列。

**账号**：令牌 v2 同时签设备与账号；登录后设备归属不变，账号只扩大可见范围；
PBKDF2 120k 次迭代；登录错误不区分"邮箱不存在"与"口令错"；账号页可登录、注册、退出。

**收尾**：注销账号（先解除认领再删）、注销即吊销、窗外游标分页、跨会话情绪趋势、
词库可改与回滚、可打印记录页、只读账号视图。

**真实模型与自救**：本机档默认接 Ollama；恢复码、改口令、退出其他设备；
认领改为显式确认；一次性分享链接；Firefox 本机转写；临床审核记录。

证明与数据：测试 119 → 155；34 条正式集、25 条安全集、8 条流程集跑通；
真实模型 P50 22 秒 / P95 30 秒（CPU）。细节见 [评估与测试集](02-评估与测试集.md)。

## 当前边界

按"会不会影响上线"排序：

1. **真实模型只有 CPU 数据**：qwen3-8b + bge-m3 在本机跑通，单轮 30–60 秒；
   没有 GPU / 云端 API 的延迟、成本与质量对比。
2. **容器默认仍是桩**：`--ai` 才起容器内 Ollama；本机 jar 档默认接 Ollama，两者不一致。
3. **正式集仍小**：知识 34 条、安全 25 条、流程 8 条；三组对照只跑了 4 条样本，不能当结论。
4. **pgvector 只压过一轮**：64 并发 P95 535 ms；HNSW 参数未调，大语料重嵌入耗时未测。
5. **认知检验只收反例**：`evidence_for` 仍是空字段，要采"支持证据"得改协议。
6. **账号缺邮箱验证**：有恢复码、改口令、退出其他设备、注销；没有 SMTP、第三方登录、"只踢某一台"。
7. **限流是固定窗口**：可落库共享，但窗口边界可能瞬时放行 2 倍配额。
8. **临床审核没有签字**：有按版本的记录与清单，默认"未审核"，系统不能替医生决定。
9. **记录页不直接外发**：能打印、能生成一次性链接；打印或另存后不再受系统保护。
10. **语音跨平台**：Chrome/Edge 用浏览器识别；Firefox 依赖 Windows 语音包，Linux/容器默认没有。
11. **紧急联系人不自动外呼/发短信**：提供 `tel:` / `sms:` 入口，发送键由本人按。
12. **没有跨会话疗程与量表**：一轮走完即止，没有 `program` 概念，也没有 PHQ-9 等前后测。
