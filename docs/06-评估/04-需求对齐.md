# 需求对齐

对象是一份 10 条功能清单。逐条说明**在哪实现、怎么证明、边界在哪**——
能演示、能跑测试、能指出文件，才算对齐。

## 逐条对照

| # | 需求 | 实现 | 证据 | 边界 |
|-|-|-|-|-|
| 1 | 匿名文字倾诉 | HMAC 令牌签发身份，不登录即可用；除 `X-User-Token` 外不接受任何身份声明 | `UserTokenService`、`SessionAuthTest`（无令牌 401 / 伪造 401 / 他人 404） | 令牌是设备级，换设备即失去旧记录 |
| 2 | 语音倾诉 | Chrome/Edge 用 Web Speech；Firefox 录音后发本机 `/api/asr/transcribe`，结果落进输入框 | `room/index.html` 的 `toggleVoice()`、`AsrController`、`scripts/asr_transcribe.ps1` | 浏览器内转写不录音；本机转写音频不落库；需系统语音包 |
| 3 | CBT 框架引导识别偏差 | 五阶段由代码推进；`DistortionTagger` 标出 9 类候选偏差，检验阶段回显 | `DistortionTagger`、`DistortionTaggerTest` | 只给候选，不写诊断、不进总结、最多 3 个 |
| 4 | 危机干预预警 | 规则分流 + 自评 ≤3 进"关注"；命中即暂停并转介 | `SafetyScreenerTest`、`CrisisCardTest` | 规则来自工程常识，未经临床审核；语义通道未实现 |
| 5 | 匿名机制 | `userId` 由服务端从令牌还原，前端传入的一律忽略；账号是可选叠加层 | `CbtController.start()`、`AuthService` | 无邮箱验证；恢复靠一次性恢复码 |
| 6 | 敏感词过滤 | 归一化（NFKC/零宽/全角/重复字）+ 三级动作（block/mask/review），输入输出分 scope | `SensitiveLexiconTest`、`LexiconAdminTest` | 不做拼音/拆字/谐音对抗；门槛是结构门槛，不是内容审核 |
| 7 | 紧急联系人触发 | 会话级联系人 + 账号级默认（登录后在账号页填一次，新开一轮自动带上）；暂停时生成危机卡片（当地求助路径 + 联系人 + 可复制的话），后台可标记已处理 | `CrisisCard`、`PUT /{id}/contact`、`/internal/sessions/{id}/ack` | **不自动外呼、不发短信** |
| 8 | 心理咨询专用 System Prompt | `prompts/cbt/counselor.md` 作为共享前言，拼在两处模型调用最前 | `CbtFlow.system()`、`PromptAssetTest` | 它是禁止清单，不是"咨询师人格"；流程仍由代码推进 |
| 9 | 情绪状态追踪 | 用户自评 0–10（只能点）+ 情绪词标签；序列落库，房间画折线；跨会话按天聚合 | `MoodPoint`、`POST /{id}/mood`、`GET /api/cbt/mood/trend` | 单点低分不等于危机；不插值、不预测、不下"变好了"的结论 |
| 10 | Safety Filter | 输出侧 `GuardedChatPort`：长度 / 禁句 / 敏感词 / 与输入重合度 → 重写 → 模板兜底 | `GuardRules`、`GuardedChatPortTest` | 误判代价是质量下降，漏判代价是越界话术；档位可后台调 |

## 两条"实现了但没有做满"的取舍

**语音不存音频。** 存音频等于给自己造一个高价值攻击面，而项目没有相应的加密、留存、删除链路。
转文字后即弃：功能在，风险不在。

**联系人只触发"人"，不触发"通道"。** 自动发短信/打电话需要资质与责任约定，误报一次就是真实伤害。
系统做的是：把热线摆在最前、把联系人摆出来、把该说的话写好，**发送键留给用户**。

## 演示路径（约 3 分钟）

1. `/room/` 点小人 → 点麦克风说一句（Chrome），文字自己出现在输入框；
2. 点情绪刻度 `3` → 提示"要不要先停一下"，后台该会话变成**关注**；
3. 走完"情境 → 想法"，输入"我肯定会被开除，一切都完了" → 检验阶段出现**灾难化**提示；
4. 另开一轮，输入"加微信详聊" → 整句被拦，流程不推进；
5. 再说"我真的不想活了" → 暂停，卡片给出你所在地区的急救与心理援助路径，留联系人后可**复制一段发给对方的话**；
6. `/internal` 该会话显示**安全暂停**、联系人、自评分，点"标记已处理"落时间；
7. `/account/` 注册 → 回房间，窗外刚才几轮还在；退出登录后本机记录仍在；
8. `/internal/settings.html` 改一条规则并保存 → 回房间发一句触发它，行为立即变化；
   再把 hold 规则删掉点保存，服务端拒绝；
9. `/internal/record.html?id=` 打印记录页，纸上包含过程、确认过的说法、情绪分与边界声明。

## 已知缺口

完整清单见 [版本记录 §当前边界](01-版本记录.md#当前边界)。与本清单直接相关的三条：

- 临床审核仍是人的事：有按版本的记录与清单，但默认"未审核"；
- 偏差词表是规则，复杂句式会漏；自评曲线没有"疗程"概念，无法做疗程内对比；
- 语音在 Linux/容器默认不可用（依赖 Windows 语音包）。
