# ADR-0004：产品边界停在"不诊断"

- **状态**：已接受
- **日期**：2026-11-17
- **相关**：[§1.2](../01-方案/01-产品边界与总体架构.md)、[§2.4.3](../01-方案/02-相关方案横向对比.md)、[§2.7](../01-方案/02-相关方案横向对比.md)

## 背景

初稿只写了"暂不做临床诊断"，没写为什么。而"为什么"决定了这个边界会不会在下一版被轻易推翻。

## 决策

产品边界固定在**"自助技能训练工具"**：不做筛查评级、不做分诊结论、不做治疗决策、不给药物建议。安全分流发现风险时只做**硬编码的转介**（120 / 心理援助热线 / 精神科门诊），不给出风险等级判断。

## 备选方案与被否原因

| 方案 | 为什么没选 |
|-|-|
| 做"AI 治疗" | 一旦声明疗效即进入医疗器械监管（De Novo / 510(k) / 二类三类），周期以年、费用以百万计；Woebot 关停 C 端的公开理由正是监管成本 + LLM 监管路径未明 |
| 做"筛查 / 分诊" | 需要牌照与真人供给，本质是平台生意，不是本方案的能力优势 |
| 做"风险评级"（高/中/低） | 评级即诊断的边缘形式，且误报成本极高；只给转介路径不给等级，责任边界更清楚 |

## 后果

**好处：** 不必取得医疗器械资质；验收标准从"疗效"转为"流程完整性与记录可读性"；安全策略可以做得更保守。

**代价：** 没有护城河式的临床证据；C 端付费意愿低（[§2.4.3](../01-方案/02-相关方案横向对比.md) 已论证根因是支付方缺位）；销售对象必须是机构（学校、企业、咨询机构），不是患者个人。

**复查触发条件：** 拿到医疗器械注册路径与临床合作方（有伦理审批、有 PI）；或目标市场出现数字疗法报销通道（如德国 DiGA 类）。

## 备注

这条边界是**经济学理由**，不是道德理由。评审时不要用"更保守更安全"来解释它——那样一旦有人愿意付监管成本，边界就会被无成本地推倒。
