为什么这样改

现状的问题不是缺颜色，而是缺层级：所有按钮同权、所有状态都是胶囊、所有区域都有边框。新版把“当前项、操作、证据”分开，让视线先落在问题上，再落在命中上，最后落在证据上。

  1. 强调色只做两件事：标当前项，标引用来源。面积控制在单屏 5% 以内，不做装饰。
  2. 三套字体分工：衬线负责“这是读物”，无衬线负责“这是操作”，等宽负责“这是状态和分数”。
  3. 状态用点加文字，不用红黄绿胶囊；只有安全转介才用红色。
  4. 分数拆开显示：RRF、向量 v、词法 t 三列并排，避免把“双路”误读成语义已经成立。
  5. 证据常驻右栏，引用做成句内上标 + 脚注，不做贴在句子后面的小胶囊。
  6. 底部状态条说真话：当前向量模型、生成模型、存储档位都写出来，避免把 stub 当成真实模型。
