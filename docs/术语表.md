# 术语表

统一口径用。同一个词在正文、代码、评估表里必须同义。

## 业务

| 术语 | 口径 |
|-|-|
| 知识学习 | 心理学科普与理论学习场景，对应 `KnowledgeFlow` |
| CBT 自助 | 结构化认知行为练习，对应 `CbtFlow`；**不称"治疗"** |
| 一轮 | 从选定一个具体事件，到用户确认行动计划并复盘的完整过程 |
| 自动思维 | 情境触发后自动浮现的想法，CBT 的核心工作对象 |
| 平衡思维 | 经过证据检验后形成的替代性想法；不是硬拗正面 |
| 用户确认 | 用户明确表示接受某条想法或计划；是状态推进的必要条件 |
| 转介 | 命中安全规则后停止普通流程，给出求助路径；不做风险分级 |

## 技术

| 术语 | 口径 |
|-|-|
| 证据单元（evidence） | 带结构化属性的知识片段，落 `kb_evidence` 表；区别于普通 chunk |
| 父块 / 子块 | 父块=章节级上下文，子块=可检索的最小知识点；子块持父块引用 |
| 混合检索 | 向量检索 + 全文检索 + 元数据过滤，结果用 RRF 融合 |
| RRF | Reciprocal Rank Fusion，按排名倒数加权融合多路检索结果 |
| 重排（rerank） | 放大候选池后重新排序，再截断；四档：`none` / `lexical` / `fixture` / `http` |
| 引用校验 | 检查"引用是否真的支持该陈述"，不是"引用是否相关" |
| 会话（session） | 业务对象，落 `cbt_session`；用户可见的事实来源 |
| 运行时快照（Checkpoint） | 流程恢复所需的状态；当前由会话字段承担，未引入框架 Checkpoint |
| threadId | 会话的执行标识；当前与 `sessionId` 一一对应 |
| 中断（interrupt） | 流程主动挂起、把控制权交回用户的点；CBT 只保留"确认"一处 |
| 节点路由 | 依据阶段与字段决定下一步；不由模型自由决定 |
| 神经符号混合 | 确定性骨架（规则 / 状态机）+ 受约束生成；本方案属此类 |

## 评估

| 术语 | 口径 |
|-|-|
| 引用支持率 | 回答中的断言能被所引证据**直接支持**的比例 |
| 无依据陈述率 | 无法追溯到任何证据的事实性陈述占比 |
| 召回率 / 误报率 | 安全分流两个方向必须同时报 |
| 三组对照 | A 通用模型直答 / B 通用 RAG / C 本方案（[方案对比 §7](01-概览/03-方案对比.md)） |
