# 术语表

统一口径用。同一个词在正文、代码、评估表里必须同义。

## 业务

| 术语 | 口径 |
|-|-|
| 知识学习 | 心理学科普与理论学习场景，对应 KnowledgeGraph |
| CBT 自助 | 结构化认知行为练习，对应 CbtGraph；**不称"治疗"** |
| 一轮 | 从选定一个具体事件，到用户确认行动计划并复盘的完整过程 |
| 自动思维 | 情境触发后自动浮现的想法，CBT 的核心工作对象 |
| 平衡思维 | 经过证据检验后形成的替代性想法；与"积极思维"不同，不是硬拗正面 |
| 用户确认 | 用户明确表示接受某条想法或计划；是状态推进的必要条件 |

## 技术

| 术语 | 口径 |
|-|-|
| 证据单元（evidence） | 带结构化属性的知识片段，落 `kb_evidence` 表；区别于普通 chunk |
| 父块 / 子块 | 父块=章节级上下文，子块=可检索的最小知识点；子块持父块引用 |
| 混合检索 | 向量检索 + 全文检索（BM25）+ 元数据过滤，结果用 RRF 融合 |
| RRF | Reciprocal Rank Fusion，按排名倒数加权融合多路检索结果 |
| 引用校验 | 检查"引用是否真的支持该陈述"，不是"引用是否相关" |
| Checkpoint | Graph 运行时可恢复的状态快照；≠ 业务数据库 |
| threadId | Graph 执行状态标识，一个 CBT 会话对应一个稳定 threadId |
| interrupt | Graph 的主动挂起点，把控制权交回用户 |
| 节点路由 | 依据 State 字段决定下一节点；不由模型自由决定 |
| 神经符号混合 | 确定性骨架（规则 / 状态机）+ 受约束生成；本方案属此类 |

## 评估

| 术语 | 口径 |
|-|-|
| 引用支持率 | 回答中的断言能被所引证据**直接支持**的比例 |
| 无依据陈述率 | 无法追溯到任何证据的事实性陈述占比 |
| 召回率 / 误报率 | 安全分流两个方向必须同时报 |
| 三组对照 | A 通用模型直答 / B 通用 RAG / C 本方案（[§2.8](01-方案/02-相关方案横向对比.md)） |
