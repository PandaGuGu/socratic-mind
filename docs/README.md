## 七、编号与命名约定

1. 目录用 `NN-中文名`，`NN` 两位数字，只表示"归类顺序"，不表示阅读顺序。
2. 方案章节文件用 `NN-章节名.md`，`NN` 就是章号，与正文标题里的"第 N 章"必须一致。
3. 章内小节号 `N.M`，更深一层 `N.M.K`；引用小节写 `§4.3`。
4. 一张表只讲一件事；跨章共用的表放到引用它的那一章，其它章只链接不复制（避免两份真值）。
5. 图优先用 mermaid 写在正文里，只有截图和外部导出件才进 `assets/`。
6. 文件名不带空格、不带版本号；版本靠 git，状态靠 front-matter 的 `status`。
